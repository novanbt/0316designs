# 0316 Designs — Minimalist Interior Design Studio Singapore

A modern, responsive, luxury portfolio and landing website designed for **0316 Designs** (Singapore), curated by Shawn Tan.

## Brand Identity & Aesthetic
- **Warm Minimalist Palette**: Deep warm charcoal (`#1a1917`), refined terracotta/copper accent (`#C17F59`), muted sage green (`#8B9A7B`), and soft cream (`#F0EDE8`).
- **Editorial Typography**: Cormorant Garamond serif headlines paired with clean, architectural DM Sans sans-serif body typography.
- **Micro-interactions & Polish**: Subtle frosted glassmorphism, glowing hover accents, and refined smooth scroll transitions.

## Features
- **Curated Portfolio**: Interactive project category filtering (Residential, Carpentry, Commercial).
- **Interactive Blueprints Modal**: Vector SVG architectural section drawing and floorplan viewer.
- **Image Lightbox**: Fullscreen gallery view with keyboard navigation (<kbd>ESC</kbd>, arrows).
- **Private Commission Inquiry**: Interactive drawer modal for consultation inquiries with feedback notifications.
- **Responsive Architecture**: Mobile navigation drawer with smooth transitions.

## Tech Stack
- HTML5, Vanilla CSS3, JavaScript (ES6+)
- Tailwind CSS
- Google Fonts (*Cormorant Garamond*, *DM Sans*) & Material Symbols Outlined

## Getting Started
Open `index.html` in any modern web browser or serve locally:
```bash
npx serve .
```

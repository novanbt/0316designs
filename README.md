# Chang Architects — Editorial Architecture & Interior Studio

A modern, responsive, luxury portfolio and landing website designed for **Chang Architects** (Singapore).

## Features
- **Nocturne Atelier Design System**: Bespoke dark luxury palette (`#141311` soot espresso, `#edc06b` champagne gold, `#e6e2de` ivory) with frosted glassmorphism.
- **Curated Portfolio**: Interactive project category filtering (Residential, Commercial, Hospitality).
- **Interactive Blueprints Modal**: Vector SVG architectural section drawing and floorplan viewer for *The Contemporary Residence (16 Morse Road)*.
- **Image Lightbox**: Fullscreen gallery view with keyboard navigation (<kbd>ESC</kbd>, arrows).
- **Private Commission Inquiry**: Interactive drawer modal for consultation inquiries with feedback notifications.
- **Responsive Architecture**: Mobile navigation drawer with smooth transitions.

## Tech Stack
- HTML5, Vanilla CSS3, JavaScript (ES6+)
- Tailwind CSS
- Google Fonts (*Playfair Display*, *Manrope*) & Material Symbols Outlined

## Getting Started
Open `index.html` in any modern web browser or serve locally:
```bash
npx serve .
```
